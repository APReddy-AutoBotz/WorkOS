# Scoped manual invoice billing attestation

WOS-INV-006/007/008, WOS-INT-002/003/005, WOS-GOV-002 and the commercial spec require the `Exported → Billed/Confirmed` terminal transition, permanent occupancy, immutable artifact and one informational canonical event. Billing confirmation is a distinct permission. This branch depends on PR108; it is not stack integration or release acceptance.

A currently authorized, scoped user explicitly attests a downstream confirmation against the exact accepted artifact ID/version, checksum, native-currency total and a user-entered reference. The UI and retained record call it `MANUAL_ATTESTATION`: this is not provider verification, invoice issuance, payment or a general-ledger posting. A separate opt-in capability has no seeded roles or user grants. The transaction records actor, operation, reason and source version, atomically moves the batch once to `Billed/Confirmed`, and retains the original artifact and occupancy. Canonical informational notification uses explicit scoped configuration, preserves failure evidence and permits an independently authorized recovery without impersonation. No provider call or external delivery occurs.

Before publication, prove the real React/API/PostgreSQL path, wrong artifact or changed total, stale or unauthorized actor, concurrent confirmations, same-key replay, foreign scope, no reopen/cancel/redelivery, immutable bytes, notification failure isolation and different-actor recovery. Verify additive fresh and populated upgrade/replay with no grants, an affected independent clean-checkout subset on a frozen source, and unchanged hosted CI. Buyer-specific reference syntax, external provider verification, taxes, currencies, accounting rules, external alert delivery, formal review, integration, UAT and release remain open.

The populated upgrade fixture runs the exact prior PR108 notice producer (Git blob `43f9fbc9984402a526ac52b76d30f3483644a89d`) in a disposable pre-086 API, creates a synthetic accepted export and in-app event, then applies 086 and compares the prior artifact bytes, occupancy, notices, history and grants before and after replay. The confirmation reference in all tests is synthetic.
