# Next bounded invoice workflow — prospective planning only

WOS-INV-006/007/008, WOS-INT-002/003/005, WOS-GOV-002 and the commercial spec require the `Exported → Billed/Confirmed` terminal transition, permanent occupancy, immutable artifact and one informational canonical event. Billing confirmation is a distinct permission. The current combined CSV/in-app notification candidate remains unmerged and has not yet passed hosted acceptance, so no new implementation or publication is implied by this plan.

Conservative candidate boundary: explicit, auditable user-attested downstream confirmation tied to the exact accepted artifact ID/version, checksum, native-currency control total and user-supplied reference; label it as an attestation, not provider verification. Require a new opt-in scoped capability with no grants/defaults; preserve current invoice, actor and source scope, separated from export authority. No provider call, invoice issuance, general-ledger posting or autonomous claim of payment. Record idempotency, actor, operation, reason and immutable source/version evidence; atomically move to Billed/Confirmed once and keep occupancy and prior CSV unchanged. Reuse canonical informational notification configuration, preserve its delivery-failure isolation, and permit only retrieval or status thereafter.

Before any implementation, reconcile existing acceptance/specs, determine a safe explicit attestation contract under the user's delegated product judgment, document why it does not claim provider validation, and recheck sole ownership and protected runs. Cover real React/API/PostgreSQL path, wrong artifact or changed total, stale or unauthorized actor, concurrent confirmations, same-key replay, foreign scope, no reopen/cancel/redelivery, immutable bytes and failure isolation. Buyer-specific reference syntax, external provider verification, taxes, currencies and accounting rules remain explicitly unconfigured. Complete the currently running source gates first; this note is planning, not an additional write or claim of completion.
