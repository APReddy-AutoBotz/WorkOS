## Boundary

An explicitly authorized, currently scoped finance actor may request one CSV export from an `Approved` invoice batch whose exact final approval, retained whole-item/event/source lineage, current occupancy, native currency and control total are independently revalidated in one transaction. Introduce only opt-in permission definitions, never role/user grants or defaults. Choose an explicit versioned WorkOS CSV schema for the currently supported T&M source; preserve each batch/line/item/event/source identifier and version, selected period, native currency and exact decimal amount in deterministic line order. Encode the immutable byte sequence and record schema version, artifact ID/version, SHA-256, line count, total, generated UTC timestamp, actor, operation and request identity. The artifact bytes, control record, `Approved → Exported` transition and redacted audit commit atomically. Occupancy remains unchanged and permanent after acceptance.

A same-key identical request reads the exact accepted artifact and receipt; changed input or artifact identity conflicts. After acceptance, authorized retrieval/redownload returns the stored bytes and checksum without regeneration or another transition. A confirmed pre-commit generation failure records sanitized failure evidence while preserving the `Approved` state and all occupancy; an uncertain write is reconciled by its original receipt, never automatically retried. Cancellation and generic reopen are refused after export. Existing approved history and source bytes remain immutable. No provider call, email, statutory invoice, ledger posting, exchange conversion, live scheduling or automatic external delivery is included.

## Acceptance before publication

Prove real React/API/PostgreSQL creation and byte-for-byte retrieval of an approved T&M batch CSV; exact line/event/source and control-total reconciliation; same-key and concurrent replay; changed-payload and duplicate export refusal; pending/unapproved/foreign/unauthorized/stale-source denial; complete rollback and recorded failure behavior; no cancellation/reopen after export; retained permanent occupancy; scope switches and uncertain responses; additive fresh/populated upgrade and replay with no grants. Verify normal CSV quoting and formula-safe representation without altering retained amounts, and verify any derived representation against its explicit schema contract. Use targeted development checks, independent exact-frozen-source affected tests and unchanged hosted CI. Provider acceptance, downstream billing confirmation, correction/reversal, other source models, broader reporting parity, formal review, integration, UAT and release remain open.
