# Purchase order release

WOS-COM-013 and WOS-COM-014. Before a buyer assigns charges to a purchase order, an authorized commercial reviewer can record release of the exact saved order. In the purchase order list, choose **Inspect release**, verify the currency, limit, dates, warning threshold and contract version, and enter the external approval reference and reason. Release applies to an order with positive value whose dates include today in UTC, under the active contract and applicable terms. The reviewer requires commercial view, manage and the opt-in purchase order release permission. The original creator and accounts linked to the creator's employee record cannot release the order.

Migration 076 stores one append-only scoped release per order. Its foreign key identifies the immutable order and its terms. The protected receipt retains the actor, role, authorization reference, reason, operation and time. The general audit records the status change. A retry with the same order, actor, role and submitted evidence returns the existing receipt. A competing release or conflicting retry fails. Drafts from earlier versions start with no release. Resolved releases are excluded from the draft-order count in closure readiness.

To suspend new releases, withdraw the dedicated release grant and preserve existing receipts.

## Assign an approved invoice line

WOS-COM-013 and WOS-RPT-003. Inspect an approved T&M or milestone batch in Invoice CSV export, inspect the line’s order allocation, then enter the released order number and reason. The order must match the contract, the retained contract version, currency and applicable charge date. The server obtains the amount from the immutable invoice line. Assignment requires current invoice preparation and export-view authority, access to the batch’s source evidence, commercial management and purchase-order release authority. Each line can use one order. Unassigned lines remain outside PO balances.

Migration 077 records the assignment and audit atomically. Concurrent allocations serialize on the purchase order. Available value equals the order limit less active commitments and gross consumed charges. The threshold includes commitments and consumption. An over-limit commitment fails in full. Cancellation frees the commitment. Export retains it, and downstream billing confirmation moves it to consumed. An applied credit has its own accounting evidence and does not automatically replenish purchasing authority. The purchase-order release panel shows the aggregate in the order currency to authorized managers.

To roll back the UI or stop new assignments, preserve the append-only table and its reads for existing commitments. Migration 078 extends the database guard to positive milestone charges under WOS-COM-008 and WOS-COM-013. The independently approved eligibility event supplies the charge date. Its retained contract version, currency, amount and evidence must agree with the invoice line. Milestone access and visibility of every batch source are required. A forward migration can restore the earlier guard for new writes while preserving existing allocations and balances. Split allocations and PO credit adjustments remain pending.
