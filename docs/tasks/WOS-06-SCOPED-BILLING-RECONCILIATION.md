# Scoped T&M billing reconciliation (local development boundary)

Requirement lineage: WOS-INV-001/003/006/008 and WOS-RPT-007; Reporting and Analytics Specification, “Read models and reconciliation”. This is a bounded T&M read model, not full multi-source report acceptance.

Finance readers with the existing invoice-draft view authority can inspect scoped approved-unbilled item versions, their eligibility event and retained T&M source, current occupancy, and the associated batch and retained export/confirmation identifiers. An item without occupancy is explicitly available only if its retained source is still current. A cancelled line is historical, not a current occupancy. No source, eligibility, occupancy, finance state or permissions are mutated by this report.

The query applies current organization/entity and worker scope before returning rows. A batch is exposed only if the existing invoice-draft visibility rule permits all its workers. Read in a single repeatable-read transaction and use decimal arithmetic in PostgreSQL for per-currency totals; do not add cross-currency amounts. Totals are limited to the explicitly visible report population, and any omitted mixed-scope occupancy is identified as a scope limitation rather than treated as available. Check source, item, line, occupancy, batch and retained artifact lineage and flag inconsistencies without claiming accounting confirmation. Keep manual downstream confirmation distinct from provider acceptance.

Acceptance: synthetic React/API/PostgreSQL journeys show an unoccupied item, acquired line, cancelled release, re-batching, approved export and confirmation without changing retained artifact bytes; compare per-currency control counts/amounts with their scoped source data. Exercise mixed-scope and unauthorized users, changed organization/session, malformed filters, pagination or report bounds, same-key replay and duplicate occupancy refusal through existing contracts. Existing immutable snapshots, authorization, occupancy guards and export state remain unchanged. Run affected development tests and an independent fresh-source subset including typecheck, build, server and browser paths. No external export is added in this slice: audited report-export evidence, other source families, reversal/supersession, integrated stack acceptance and final reviews remain outstanding.
